# Agent Directives & Workflow Rules

## Response Formatting
- Always provide a compact, concise summary in English at the end of your response, formatted specifically for easy consumption/pasting into ChatGPT.

## Automatic GitHub Synchronization
- After completing any task or response, automatically execute `push_to_github.bat --no-pause` to push all repository changes to GitHub (`https://github.com/ERPNICOLETTI/LEAKAI.git`).
